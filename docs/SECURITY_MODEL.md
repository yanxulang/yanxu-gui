# 安全模型

## 信任边界

言窗运行在言序进程内，边界分为三层：

1. 言序 VM 依据锁文件、目标、大小和 SHA-256 装载 `yanxu-gui` ABI v2 制品；
2. 言序公开层把应用值转换为固定的原生操作名和参数；
3. Rust 后端访问窗口系统、剪贴板、图片解码器和文件对话框。

应用传入的配置、事件名、图片、画布命令和自定义载荷均视为不可信输入。言序运行时、
锁定的官方后端和操作系统 API 属于受信计算基。言窗不是进程内沙箱：若攻击者已能替换
言序运行时、修改锁文件和制品，或装载任意恶意原生扩展，本库不能在同一进程内隔离它。

## 装载与 ABI

- 包清单要求 ABI v2，并为每个目标记录唯一文件、字节大小和 SHA-256；
- 后端在读取宿主表字段前验证 ABI 版本和完整结构大小；
- 参数是借用描述符，返回值由模块拥有，资源句柄显式区分借用与所有权；
- Rust panic 被 `catch_unwind` 隔离为 `GUI_BACKEND_PANIC`，不会穿过 C ABI；
- 模型互斥锁中毒后普通调用返回 `GUI_BACKEND_STATE`，清理仍可恢复锁并释放资源。

## 输入与资源限制

| 边界 | 1.0.0 限制 |
| --- | --- |
| 单次 ABI 聚合值 | 最多 65,536 个元素、合计 16 MiB |
| GUI 模型 | 最多 65,536 个节点、深度最多 256 |
| 单节点事件绑定 | 最多 128 个不同事件名 |
| 事件名 | 1 至 256 个 UTF-8 字节 |
| 图片 | PNG/JPEG，宽高各不超过 4,096，解码分配上限 96 MiB |
| 单画布 | 最多 16,384 条命令、估算存储上限 64 MiB |
| 窗口或控件尺寸 | 有限数，1 至 16,384 逻辑像素 |
| 定时器间隔 | 10 至 86,400,000 毫秒 |

值树预算对整个嵌套参数聚合计算，不能通过拆成多个同级值绕过。图片在分配像素前应用
解码限制；画布在追加命令前同时检查数量和内存。资源图在创建节点前检查总量与祖先深
度。单次原生操作超过限制时会返回稳定错误且不提交该操作；由多个原生调用组成的公开
便捷方法按调用顺序生效，调用方需要错误时全有或全无时应先自行校验全部输入。

## 资源、事件与线程

资源形成 `应用 -> 窗口 -> 布局/控件` 树，定时器属于应用。关闭父资源会先关闭子树并
释放事件和定时器回调；显式关闭、事件循环退出和 VM 析构均为幂等清理路径。每个句柄
绑定创建它的事件循环和所有者线程，跨事件循环或跨线程访问分别返回
`GUI_RESOURCE_LOOP`、`GUI_RESOURCE_THREAD`。

原生事件先深拷贝到宿主的有界队列，再在 VM 所有者线程逐项泵送。自定义载荷位于事件
`详情`字段，不能覆盖可信的顶层`类型`和`目标`。高频位置、尺寸和重绘状态可被合并；
队列压力不会创建无界线程或无界回调列表。

## 权限

- `图形界面`：装载后端并运行事件循环；
- `剪贴板`：读取或写入系统剪贴板；
- `文件对话框`：打开原生文件或目录选择器。

三项权限分别检查。图形权限不会隐式授予剪贴板或文件对话框；库也不会通过对话框结果
自行读取文件。应用仍需按照自身数据敏感度校验用户选择的路径和剪贴板内容。

## 非目标

言窗不提供进程隔离、输入内容加密、屏幕防录制、恶意字体或操作系统漏洞防护，也不替
应用实现授权、隐私同意或敏感数据擦除。文件对话框返回路径不表示该路径内容可信；剪
贴板属于系统共享状态。需要更强隔离时，应把不可信解析和业务逻辑放在受限子进程中。
