# 言窗使用与运行模型

言窗 0.1.0 面向言序 1.1.12。公开 API 全部位于 `src/主.yx`，原生实现只通过
ABI v2 暴露固定宽度值、持久回调和代际资源句柄；应用代码不接触 Rust、egui、
winit 指针或布局。

## 最小应用

项目通过言包创建：

```sh
yanbao new 我的窗口 --gui
yanbao run --manifest-path 我的窗口
yanbao build --manifest-path 我的窗口 --release --bundle
```

源码导入锁定别名，创建应用、窗口和布局，最后进入事件循环：

```yanxu
引「包:言窗」为 界面；
定 应用 为 界面.应用（「示例」）；
定 窗口 为 应用.窗口（{「标题」：「示例」，「宽」：800，「高」：600}）；
定 布局 为 窗口.纵向布局（{「间距」：12，「内边距」：16}）；
布局.文字（「你好，言序 GUI！」）；
法 关闭处理（事件）则 应用.退出（）；终
窗口.关闭时（关闭处理）；窗口.显示（）；应用.运行（）；
```

完整签名见 [API.md](API.md)，编辑器和工具可读取 `api/api-v1.json`。

## 控件、布局与样式

布局包括纵向、横向、网格、层叠和双向滚动；它们可递归嵌套。控件包括文字、
按钮、单行/多行输入、复选/单选、下拉、滑块、进度、图片、列表、分隔线、标签页、
菜单和画布。公共属性涵盖显示、启用、尺寸边界、内容、焦点、工具提示、可访问名称
与描述。控件样式支持字体、字号、前景/背景、边框、圆角、内外边距；应用主题可选
系统、浅色和暗色。

系统回退字体用于中文与扩展 Unicode；文本输入交给 winit/平台 IME。应用不应自行
拼装组合文本事件。

## 事件与线程

点击、双击、变化、焦点、键盘、鼠标、滚轮、窗口关闭/移动/缩放、DPI 和文件拖放
均投递为结构化`事件`对象；公开回调签名是`法（事件）：空`，可读取类型、目标、时间、
坐标、按键、修饰键、鼠标按钮、文字和处理状态。回调由宿主保留；原生线程只把事件深拷贝进有界队列，言序
回调只在创建 VM 的所有者线程执行。高频鼠标移动、窗口尺寸和重绘事件会合并；队列
满时不会无界分配。

定时器使用同一队列。取消定时器、关闭父资源、退出应用或 VM 析构都会恰好释放一次
回调与原生资源。窗口事件循环返回后，言窗立即清空模型，所以调试快照的存活资源数
归零，无需等待进程退出。

## 权限

使用 GUI 必须在清单声明 `图形界面 = true`。剪贴板和文件对话框分别需要
`剪贴板 = true`、`文件对话框 = true`；它们不能由图形权限隐式获得。官方言窗后端
可凭图形权限装载，但其他 ABI 扩展仍须单独的 `原生扩展`授权。

## 画布与图片

画布接受带 `类型` 字段的命令典：清空、线段、矩形、圆、文字、图片、裁剪和变换。
坐标为逻辑像素，winit/egui 按每窗口 DPI 缩放；图片接受 PNG/JPEG 字节并按 SHA-256
缓存纹理。资源推荐通过 `标准:资源` 从 YXB 读取，Bundle 不依赖源码目录。

## Bundle 与发布

`yanxu compile 项目 --release --bundle` 或相应言包命令产生当前目标的标准应用目录：

- macOS：`.app`、Info.plist、ICNS、可签名 Frameworks；
- Windows：GUI 子系统 PE、嵌入 ICO/版本/DPI 清单，安全 DLL 搜索策略；
- Linux：AppDir、Desktop Entry 和 hicolor 多尺寸图标，兼容 Wayland/X11。

Bundle 同时包含 standalone 运行时、YXB、原生库、资源、许可证与逐文件 SHA-256
清单。构建在同级随机暂存目录完成，验证通过后原子替换输出。清单的 `signing` 字段
给出平台签名顺序；签名与公证应在最后一次未签名摘要验证之后完成。
