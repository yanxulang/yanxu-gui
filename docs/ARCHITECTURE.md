# 架构

## 组件

言窗由四个发布契约组成：

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 言序公开层 | `src/主.yx` | 中文类、方法、事件包装和稳定错误详情 |
| ABI v2 后端 | `native/src` | 参数校验、资源模型、事件循环、渲染和平台服务 |
| 包元数据 | `言序.toml.in` | 版本、权限、导出、ABI 与平台制品索引模板 |
| 消费验证 | `examples/`、`tests/` | 经路径依赖和锁文件验证公开包，而非内部模块 |

`api/api-v1.json` 和 `docs/API.md` 都由公开入口生成。它们不是手写替代实现，而是
`src/主.yx` 的机器契约和阅读视图。

## 调用路径

应用导入 `包:言窗` 后，公开对象只保存一个 `原生资源`句柄。方法把固定操作名和言序
值交给 `标准:原生`；VM 根据锁图找到当前目标的动态库，验证摘要和 ABI，再调用后端：

```text
言序应用
  -> src/主.yx 中文 API
  -> 标准:原生 ABI v2
  -> native/src/lib.rs 分派与 panic 隔离
  -> native/src/bridge.rs 有界值转换
  -> native/src/backend.rs 校验、事件与渲染
  -> eframe / egui / winit / 平台服务
```

操作表在模块初始化后保持稳定。参数描述符由宿主借用；返回值由模块分配并通过模块的
`free_value`释放。资源返回独立描述符，记录资源类型、父句柄和析构函数。

## 模型与生命周期

每个`应用`拥有一个受互斥锁保护的模型。窗口、布局、控件和定时器是有编号节点；窗口
和布局形成父子树，定时器直接属于应用。ABI 句柄同时记录：

- 模型引用和节点编号；
- 资源种类；
- 创建它的宿主事件循环编号；
- 创建线程；
- 是否已经清理。

创建操作先验证父资源、配置和预算，再插入模型。关闭资源时按子节点优先顺序移除整棵
子树并释放绑定回调。关闭布局因此也会关闭其所有子布局和控件。事件循环返回后模型被
原子清空；剩余言序句柄随后析构不会重复释放。

## 渲染与窗口

`应用.运行()`调用 `eframe::run_native` 并阻塞至应用退出。第一项可见窗口作为根
viewport，其余窗口使用即时 viewport。每帧执行以下步骤：

1. 应用主题和窗口命令；
2. 收集窗口输入与关闭请求；
3. 按模型树渲染布局和控件；
4. 查找到期定时器；
5. 释放模型锁，逐项投递事件并泵送 VM 回调。

窗口关闭若未绑定处理器，会直接移除窗口子树；绑定关闭处理器时先投递事件并取消平台
默认关闭，由应用决定调用`窗口.关闭()`或`应用.退出()`。根窗口与附加窗口遵循相同
模型生命周期。

## 事件

后端把平台事件规范化为固定字段的典，公开层再包装成`事件`对象。`类型`、`目标`和
`时间`由后端产生；坐标、按键、修饰键、鼠标按钮、文字、处理状态和详情始终存在。
自定义事件载荷只进入`详情`，不能伪造可信顶层字段。

宿主保留回调编号，原生后端不直接在平台线程执行言序代码。事件深拷贝进宿主有界队列
后，在 VM 所有者线程泵送。重新绑定同名事件会释放旧回调；取消定时器也立即释放其回
调。事件名和单节点绑定数量均有硬上限。

## 制品与发布

根 `言序.toml` 和 `dist/` 是当前平台的本地生成物，不受 Git 跟踪。
`scripts/prepare-current.sh` 从 release 构建复制一个真实动态库，并写入目标、路径、
大小和 SHA-256。发布 CI 在六个原生托管目标分别执行相同步骤，再汇总为完整索引：

```text
x86_64-unknown-linux-gnu      aarch64-unknown-linux-gnu
x86_64-apple-darwin          aarch64-apple-darwin
x86_64-pc-windows-msvc       aarch64-pc-windows-msvc
```

运行时不下载、编译或猜测其他平台的制品。目标不匹配、摘要或大小漂移、ABI 导出缺失都
必须在装载或发布门禁中失败。

## 变更规则

- 公开方法与类型变更同时更新源码、JSON API、Markdown API、规格和迁移说明；
- 新原生操作先定义稳定错误与资源语义，再暴露公开包装；
- 不把 egui/winit 类型、指针或线程对象泄露到言序 API；
- 不通过全局可变状态共享应用模型；
- 1.x 保持现有公开签名和错误码语义，破坏性变化留给新的主版本。
