# 言窗 1.0.0 发布说明

## 摘要

言窗 1.0.0 建立首条稳定桌面 GUI 版本线。公开 API 使用中文言序对象，原生后端通过
ABI v2 封装 eframe/egui 与 winit，并为 Windows、macOS、Linux 的 x86-64 和 ARM64
定义精确制品目标。最低言序版本为 1.1.12。

## 主要能力

- 应用生命周期、主题、多窗口、位置、DPI、全屏、置顶和尺寸约束；
- 纵向、横向、网格、层叠和双向滚动布局，可递归嵌套并显式关闭；
- 文字、按钮、输入、选择、列表、标签页、菜单、图片、进度、滑块和画布；
- 键盘、鼠标、焦点、变化、窗口、拖放、自定义事件和定时器；
- 中文与扩展 Unicode 字体回退、平台 IME、可访问名称和描述；
- 剪贴板、打开/保存/多选/目录对话框及独立权限；
- 结构化错误详情、调试资源快照和稳定 `GUI_*` 代码。

## 稳定与安全

后端先验证 ABI 表大小，再解码有界值；借用句柄不会按自有资源释放。资源图、回调绑定、
图片解码和画布均有硬上限。资源绑定创建线程和事件循环，关闭父资源会清理子树。Rust
panic 与模型锁中毒被隔离，清理路径仍可释放回调和资源。

当前 quick-xml 安全公告通过锁定的 Wayland scanner 补丁修复。直接依赖版本和许可证
见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 兼容与破坏性变化

- 最低言序由 1.1.7 提升至 1.1.12；
- 包版本和消费范围由 0.1 改为 1.0 / `^1.0`；
- 只提供 ABI v2 制品，旧动态库不可复用；
- 配置类型、尺寸、布局、控件值和计时器范围改为严格拒绝；
- 跨线程、跨事件循环和关闭后资源访问不再容忍；
- 原生稳定码应通过`错误详情`读取。

迁移步骤见 [MIGRATION.md](MIGRATION.md)，完整矩阵见仓库根
`COMPATIBILITY.md`。

## 权限

| 能力 | 权限 |
| --- | --- |
| 窗口与事件循环 | `图形界面` |
| 剪贴板读写 | `剪贴板` |
| 文件和目录对话框 | `文件对话框` |

应用只应授予实际使用的权限。文件对话框只返回选择结果，不会替应用读取文件。

## 已知限制

- 不支持 Linux musl、WebAssembly、移动平台或 32 位目标；
- 非零布局`伸缩`尚未实现；
- 图片仅支持受限 PNG/JPEG；
- 高频事件可能合并，定时器精度由平台调度决定；
- 渲染像素和系统对话框外观不保证跨平台完全一致；
- 1.0.0 不给出跨设备统一 FPS 或内存承诺。
